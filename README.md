# Рулилка — обновления прошивки

Открой [страницу обновления](https://vinsh01.github.io/rulilka-updates/) в Chrome или Edge (компьютер или Android — на iPhone/iPad Web Bluetooth не работает), нажми «Найти устройство «Rulilka»» и «Скачать и установить последнюю версию».

Этот репозиторий содержит только скомпилированные бинарники прошивки и страницу обновления — исходный код прошивки не публикуется здесь.
